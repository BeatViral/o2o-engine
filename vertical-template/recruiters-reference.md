# Recruiters Reference (Current Baseline)

This document records the first vertical implementation used as the clone source.

## Product Name

- O2O for Recruiters
- Recruitment Operating System Generator

## Core Promise

- Weak job brief in
- Blind spot diagnosis first
- Corrected search thesis second
- Full recruiter operating system third

## Mandatory Diagnosis Layer

Recruitment contract includes:
- stated need
- likely real need
- false assumptions
- hidden failure modes
- wrong-candidate risks
- missing success definition
- compensation or level mismatch
- passive candidate reality
- corrected search thesis

## Core Build Outputs

- Hidden success profile
- Candidate persona
- Wildcard profile
- Passive search strategy
- Boolean strings
- Screening rubric
- Interview architecture
- Red flags
- Outreach message
- Shortlist scorecard
- 21-day search sprint
- Client briefing notes
